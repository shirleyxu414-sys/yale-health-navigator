Safety demo

These defenses run in code, before any model call. Everything below ran live just now, and no model was called, so no tokens were spent.

1. Prompt-injection defense

Everything typed into the app is data, never instructions. Attempts to give the app orders are refused.

2. No-diagnosis guardrail

Questions like "what do I have?" or "is this serious?" are refused in code and sent to a clinician.

What was typedResultWhat the app said

3. Grounding check

A coverage claim is shown only if its words, and every number in it, are in the rule files. Otherwise it is replaced.

CaseModel saidResultWhat the person would see

4. Budget guard

Each session has a cap on input tokens. A run that would go over it stops before the model is called.
